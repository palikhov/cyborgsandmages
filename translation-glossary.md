# Словарь терминов для перевода

Словарь заполняется вручную. Указанные здесь переводы используются в статьях с учётом контекста. Явные указания в текущем запросе имеют приоритет.

Для нового термина добавьте строку в таблицу:

- **Оригинал** — термин на языке исходной статьи; варианты написания и сокращения можно указать в той же ячейке.
- **Перевод** — выбранный русский вариант в начальной форме.
- **Контекст** — игровая система, редакция или значение, для которого применяется перевод. Пустая ячейка означает общий вариант.
- **Примечания** — особенности употребления, регистр, сокращения или нежелательные варианты; поле необязательно.

Если у термина разные переводы в разных контекстах, добавьте отдельную строку для каждого значения. Пустые строки и строки без перевода не задают правило.
