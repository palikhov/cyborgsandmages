# Выборка из реестров

Запускай из корня репозитория:

```text
node .agents/skills/translate-publish-article/scripts/lookup-registries.mjs <input.json>
```

Вместо файла можно передать `-` и JSON через стандартный ввод. Временный файл, если нужен, сохраняй вне публикуемого контента. Формат входа:

```json
{
  "articleUrl": "https://example.com/article",
  "links": ["https://example.com/related#section"],
  "verifiedAliases": []
}
```

Сначала проверь URL оригинала (можно с пустым `links`), затем после извлечения статьи передай canonical URL и все уникальные содержательные абсолютные ссылки одним вызовом. Если они уже известны, достаточно одного вызова.

Помощник только читает реестры, не обращается к сети и возвращает:

- `article.translations` — существующие переводы оригинала; при совпадении не создавай дубликат;
- `article.externalReferences` — разделы и пути старых статей, где требуется заменить ссылку;
- `links[].translations` — соответствия для внутренних ссылок;
- `links[].externalReferences` — существующие разделы для регистрации оставшихся внешних ссылок;
- `line` — номер строки соответствующей записи реестра;
- `ambiguousTranslation` — найдены разные пути перевода одного URL; выясни правильную цель до замены;
- `needsVerification` — возможные совпадения с другим протоколом или `www`, которые ещё нельзя считать эквивалентными.

Якоря, завершающие `/` и известные параметры отслеживания (`utm_*`, `fbclid`, `gclid`, `dclid`, `msclkid`, `_ga`, `_gl`, `mc_cid`, `mc_eid`) исключаются из сравнения. Содержательные и неизвестные параметры сохраняются. Прочие параметры удаляй только после проверки, что это отслеживание.

Проверь относящиеся к задаче `needsVerification` по перенаправлениям или canonical URL. Подтверждённые альтернативные адреса, включая исходный URL при перенаправлении на canonical, передай повторно:

```json
{
  "articleUrl": "https://example.com/article",
  "links": [],
  "verifiedAliases": [
    {
      "urls": ["http://www.example.com/article", "https://example.com/article"],
      "evidence": "Проверено: первый URL перенаправляет на второй"
    }
  ]
}
```

`evidence` заполняй только по фактически выполненной проверке: помощник доверяет этому полю, но сам эквивалентность не подтверждает. Не подставляй непроверенные варианты. Сохраняй исходные якоря отдельно и переноси их только при наличии цели в переводе. Если проверка недоступна, сохраняй ссылку внешней; для возможного дубликата самой переводимой статьи сначала разреши неопределённость.

Отсутствие совпадения означает только отсутствие записи в реестре. Проверку slug и ссылки на оригинал среди публикаций выполни отдельно, как указано ниже. Помощник не обнаруживает произвольные перенаправления между разными путями и доменами: известные по проверке адреса передавай через `verifiedAliases`.

При обновлении реестров читай только найденные разделы и нужные соседние строки; для добавления и сортировки обрабатывай файл локально без вывода полного содержимого. Перед правкой учитывай, что номера строк могли измениться: сверяй URL. После изменения повтори выборку и проверь затронутые записи и файлы. Помощник не заменяет проверки полноты перевода, реестров и фактических ссылок.
