Ткачество заклинаний — это искусство обращения к гобелену магии, который пронизывает все вещи. Использование метамагии тонко изменяет обычный поток заклинаний, принося больше силы заклинателю ценой ячейки более высокого уровня заклинаний. Усиленный ритуальный кастинг заклинаний заряжает заклинания в момент их произнесения, а не в момент подготовки; таким образом, заклинатель не должен жертвовать уровнями заклинаний, чтобы произнести заклинание, усиленное метамагией. Ритуал обеспечивает дополнительную силу.

Заклинатель может ритуально накладывать заклинания, усиленные только теми метамагическими чертами, которые он знает, но он может использовать каждую известную черту ценой увеличения времени накладывания заклинания, жертвуя более дорогими компонентами и подвергая себя большему риску неудачи ритуала. Каждая дополнительная метамагическая черта, применяемая к заклинанию через усиленное ритуальное наложение, которая в обычных условиях увеличила бы уровень заклинания, вместо этого делает заклинание более длительным и затратным по материальным компонентам. Сумма этих дополнительных уровней составляет *добавленный модификатор уровня*. Добавленный модификатор уровня используется для определения конкретных требований усиленного ритуального наложения.

## ОГРАНИЧЕНИЯ УСИЛЕННОГО РИТУАЛА

Уровень заклинания, которое произносится, плюс добавочный уровень всех черт, усиливающих заклинание, не может превышать максимальный уровень заклинания, который заклинатель способен произнести обычным способом.

> *Пример: заклинатель 12-го уровня ещё не может творить заклинания 7-го уровня. Поэтому самый мощный ритуал, которым он способен усилить заклинание * стук * 2-го уровня, добавляет +4 уровня заклинания (2 + 4 = 6 — высший доступный ему уровень).*

## ВРЕМЯ ПРОИЗНОШЕНИЯ УСИЛЕННОГО РИТУАЛА

Чтобы определить время произнесения усиленного ритуального заклинания, сначала определите базовое время ритуального заклинания заклинания в соответствии с его обычным временем произнесения (см. таблицу). Время ритуального заклинания равно этому базовому времени, умноженному на общий добавленный модификатор уровня усилений:

(базовое ритуальное время) x (добавленный модификатор уровня)

Любое время произнесения, превышающее один час, требует проверки Ритуального Произнесения с уровнем сложности 10 + уровень заклинания. (Для этого уровня сложности используйте исходный уровень заклинания, а не усиленный уровень.) Провал проверки Ритуального Произнесения приводит к тому, что магические энергии искажаются и отбрасываются обратно на заклинателя, нанося (уровень заклинания + добавленный модификатор уровня) очков урона. Усиленный ритуал все равно успешно произносится в случае провала проверки Ритуального Произнесения.

| **Обычное время кастинга** | **Время кастинга базового ритуала** |
| --- | --- |
| Свободное действие | 1 полный раунд |
| 1 действие | 5 полных раундов |
| Полный раунд | 5 минут |
| Прочее | 10 раз больше обычного времени заклинания |

## МАТЕРИАЛЬНЫЕ КОМПОНЕНТЫ УСИЛЕННОГО РИТУАЛА

Усиленные ритуальные заклинания требуют дополнительных материальных компонентов сверх тех, которые обычно требуются для произнесения заклинания. Эти дополнительные компоненты представляют собой редкие материалы, которые должны быть потрачены для привлечения ещё большей силы для эффекта заклинания. Для божественных заклинателей эти компоненты обычно состоят из священного благовония, малых жертвоприношений или подобных атрибутов, предлагаемых богам. Для арканических заклинателей эти компоненты могут представлять собой травы, минералы или любую другую форму ритуальных атрибутов.

Независимо от того, что это за ингредиенты, общая стоимость этих материалов равна числу золотых монет, равному:

25 x (добавленный модификатор уровня)

## ОСОБЫЕ ПОДВИГИ

**Возвышение заклинания**: Подвиг «Повышенный заклинание» можно использовать, при этом разница между фактическим уровнем заклинания и новым уровнем заклинания используется для расчета добавочного модификатора уровня.

**Быстрое заклинание**: Подвиг «Быстрое заклинание» не может быть добавлен к усовершенствованному ритуальному заклинанию. Однако, если черта используется обычным образом, а затем ускоренное заклинание усиливается, время ритуального сотворения может быть значительно сокращено (согласно таблице выше).

**Беззвучное заклинание**: Подвиг «Беззвучное заклинание» не может быть добавлен к усовершенствованному ритуальному заклинанию. Если заклинание, подготовленное с эффектами черты «Беззвучное заклинание», используется для совершения усовершенствованного ритуального заклинания, преимущества черты аннулируются.

**Фокусировка заклинаний**: Эта способность может использоваться в усиленных ритуальных заклинаниях для предоставления бонуса сверх обычного преимущества +2. За каждый дополнительный бонус +1 (сверх обычного бонуса +2, предоставляемого этой способностью), которым заклинатель желает усилить своё заклинание, один уровень добавляется к общему модификатору добавленного уровня усиленного ритуального заклинания.

**Пронзание Заклинаний**: Эта способность может использоваться в усиленных ритуальных заклинаниях для предоставления бонуса сверх обычного преимущества +2. За каждый дополнительный бонус +1 (сверх обычного бонуса +2, предоставляемого этой способностью), которым заклинатель желает усилить своё заклинание, один уровень добавляется к общему модификатору добавленного уровня усиленного ритуального заклинания.

**Неподвижное заклинание (*Still Spell*)**: как и «Безмолвное заклинание» (*Silent Spell*), эту черту нельзя добавлять к усиленному ритуальному заклинанию. Если для ритуала используется заклинание, подготовленное с этой чертой, её преимущества аннулируются.
