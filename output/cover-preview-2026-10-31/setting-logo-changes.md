# Единый логотип Forgotten Realms — 31 октября 2026

На девять одобренных обложек Эда Гринвуда добавлен одинаковый существующий логотип из интернета. Ширина 340 пикселей, отступ справа 36, снизу 32. Исходные иллюстрации и заголовки сохранены.

Источник: https://en.wikipedia.org/wiki/File:New_Forgotten_Realms_logo.png

Скачанный PNG: https://upload.wikimedia.org/wikipedia/en/f/fb/New_Forgotten_Realms_logo.png

Локальный исходник: `forgotten-realms-logo-internet.png`; подготовленная копия: `forgotten-realms-logo-340.png`. Ранее сгенерированный русский вариант не использован.

## Список изменений

Точные пути статей, прежние и новые имена изображений записаны в `setting-logo-changes.json` рядом с этим файлом. В каждой статье изменена только ссылка cover. Новые изображения имеют суффикс `-setting-logo.png` в `src/assets/covers/`.

- Новый путь к личеванию: a-new-road-to-lichdom.
- Забытый маг: forgotten-mage-of-the-forgotten-realms.
- Как указать бехолдеру дорогу: how-to-tell-a-beholder-where-to-go.
- Утраченные знания: lost-lore-of-the-realms-72, -75, -76.
- Парящая Маска Рока: the-floating-mask-of-doom; основа — исправленная версия v2 с мужским лицом.
- Три леди: the-ladies-three; основа — версия v2 по интернет-референсам.
- Когда маска улыбается: when-the-mask-smiles.

## Откат только логотипа

Из корня репозитория выполнить:

```powershell
node output/cover-preview-2026-10-31/rollback-setting-logo.mjs
```

Скрипт возвращает девять ссылок на прежние обложки, включая обе версии v2. Перед записью проверяет все ссылки и наличие исходников. Повторный запуск безопасен. Изображения не удаляются. Все исходники остались на прежних местах и дополнительно скопированы в `before-setting-logo/`.

Для полного отката более ранних изменений сначала выполнить этот откат логотипа, затем следовать `greenwood-changes.md`.
